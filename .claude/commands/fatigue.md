# Fatigue

Read docs/compliance.md first. Run `npm run fleet -- fatigue` (default last 28 days, `--days=N` to change). For each finding, show the driver, the window start (UTC) and what was exceeded. BFM and AFM drivers are referred for a manual check against their accreditation. A clear result is not a fitness-to-drive decision and never clears a driver to start a shift.
